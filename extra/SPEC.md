# ハンズオン題材：駐車場料金計算コンソールアプリ 仕様ドキュメント

## 1. ビジネス要件

### 1.1 対象設備

- 駐車位置の数は **20区画**で、駐車位置番号は `01` 〜 `20` の2桁固定文字列で表す
- 1区画に同時に駐車できる車両は1台のみとする
- 駐車に対しては、入庫から出庫までの利用時間に応じて料金を計算する

### 1.2 対象機能

| No  | 機能         | 概要                                                                                              |
| --- | ------------ | ------------------------------------------------------------------------------------------------- |
| 1   | 入庫登録     | 駐車位置（01-20）を指定し、入庫時刻を記録して取引ID(形式:UUID)を発行する（1つの駐車位置につき同時に1台まで） |
| 2   | 出庫精算     | 駐車位置を指定し、入庫時刻〜現在時刻の駐車時間から料金を計算・記録する                            |
| 3   | 利用状況照会 | 全20の駐車位置の空き／入庫中の状況と、入庫中の駐車位置の経過時間・現時点料金を一覧表示する        |

- 補足: UUIDとは、Universally Unique Identifier の略で、8-4-4-4-12桁の16進数をハイフンで区切った形式の識別子である。

### 1.3 入力バリデーション

| 条件                                 | 結果                                                               |
| ------------------------------------ | ------------------------------------------------------------------ |
| 駐車位置が `01`〜`20` 以外           | エラー：「駐車位置は01〜20で指定してください（入力値: <入力値>）」 |
| 入庫登録時、その駐車位置が既に入庫中 | エラー：「この駐車位置は既に入庫中です（駐車位置: <駐車位置>）」   |
| 出庫精算時、その駐車位置が空き       | エラー：「入庫記録が見つかりません（駐車位置: <駐車位置>）」       |

ただし、駐車位置の入力は1桁でも受け付け、内部的には2桁固定文字列として扱う（例: `1`という入力は `01` として扱う）。

## 2. 料金体系（ビジネスルール）

駐車場の料金体系は「30分無料 + 60分単位課金」方式で、60分の課金単位を1コマと呼ぶこととする。

### 2.1 料金の骨格

| 項目     | 内容                                           |
| -------- | ---------------------------------------------- |
| 無料時間 | 入庫から **30分間** は無料                     |
| 料金単価 | 無料時間超過後、**1コマ**(60分)ごとに**100円** |
| 課金単位 | **60分単位で切り上げ**                         |
| 上限料金 | なし                                           |

### 2.2 時間計算ルール

#### (1) 秒の扱い

入庫時刻・出庫時刻の秒は切り捨て、分単位で計算する。

例：

```text
10:32:14 → 10:32
18:45:59 → 18:45
```

#### (2) 無料時間の適用

入庫から30分以内の利用は無料とする。利用時間が30分を超えた場合、超過時間に対して60分単位の料金を適用する。

| 利用時間 | 料金     |
| -------- | -------- |
| 30分以下 | 無料     |
| 30分超～ | 料金発生 |

#### (3) 境界値の扱い

利用時間が境界値に該当する場合は、より安い料金が適用される。
| 利用時間 | 料金 |
|------|------|
| 30分ちょうど | 0円 |
| 30分1分 | 100円 |
| 90分ちょうど | 100円 |
| 90分1分 | 200円 |

#### (4) 課金計算式

(1)～(3)のルールに従って、料金は以下のルールに従って計算される。

- 利用時間の定義

  $$
  \text{利用時間} = \text{出庫時刻} - \text{入庫時刻}
  $$

- 課金対象時間の定義

  $$
  \text{課金対象時間} = \text{利用時間} - 30
  $$

- 料金計算式
  $$
  \text{料金} =
  \begin{cases}
  0 & (\text{利用時間} \leq 30) \\
  100 \times \left\lceil \dfrac{\text{課金対象時間}}{60}     \right\rceil & (\text{利用時間} > 30)
  \end{cases}
  $$

---

### 2.3 計算例

#### 例A：30分以内の駐車

```
入庫 2026-09-15 09:00 / 出庫 2026-09-15 09:25
利用時間 0時間25分

合計 0円
```

#### 例B：90分以内の駐車

```
入庫 2026-09-15 08:00 / 出庫 2026-09-15 09:25
利用時間 1時間25分
課金対象 0時間55分(1コマ)

合計 100円
```

#### 例C：90分を超える駐車

```
入庫 2026-09-15 10:00 / 出庫 2026-09-16 13:35
利用時間 27時間35分
課金対象時間 27時間5分(28コマ)

合計 2,800円
```

### 2.4 トランザクションの扱い

入庫登録および出庫精算の各操作はトランザクションの考慮は不要とする。

### 3.5 エラー系

1. 入庫登録時に既に入庫中の駐車位置を指定した場合

   ```
   番号を選択してください > 1
   駐車位置を入力してください (01-20) > 05

   [エラー] この駐車位置は既に入庫中です（駐車位置: 05）
   ==========================================
   ```

2. 出庫精算時に未入庫の駐車位置を指定した場合

   ```
   番号を選択してください > 2
   駐車位置を入力してください (01-20) > 12

   [エラー] 入庫記録が見つかりません（駐車位置: 12）
   ==========================================
   ```

3. 入力値が不正な場合（駐車位置の範囲外・非数値）

   ```
   番号を選択してください > 1
   駐車位置を入力してください (01-20) > abc

   [エラー] 駐車位置は01〜20で指定してください（入力値: abc）
   ==========================================
   ```

4. DBエラーなどその他のエラーが発生した場合

   ```
   番号を選択してください > 1
   駐車位置を入力してください (01-20) > 20

   [エラー] 予期せぬエラーが発生しました
   ==========================================
   ```

## 4. ログ出力イメージ

ログはログファイルに出力する。

### 4.1 ログに出力する内容

- アプリケーションの起動・終了に関する情報
- 参照系処理の実行に関する情報
- 更新系処理の開始と完了に関する情報
- エラーに関する情報

### 4.2 ログファイル名

ログファイルは`app-YYYY-MM-DD.log` という名前で出力される。

### 4.3 ログフォーマット

```
yyyy-MM-dd HH:mm:ss [LEVEL] メッセージ本文
```

- レベルは `INFO` / `WARN` / `ERROR` の3種類
- 業務エラー（入庫中・未入庫・範囲外）は `WARN`、インフラ障害（DB接続失敗等）は `ERROR`

## 5. システム構成

### 5.1 DB設計（PostgreSQL）
車両が特定の駐車位置に入庫してから、精算を済ませて出庫するまでの一連の利用単位を**駐車セッション**としてデータベースに保持する。

```sql
-- 駐車セッションテーブル
CREATE TABLE parking_sessions (
    id            UUID         PRIMARY KEY,
    space_number  CHAR(2)      NOT NULL,
    entry_time    TIMESTAMP    NOT NULL,
    exit_time     TIMESTAMP,
    fee           INTEGER,
    status        VARCHAR(16)  NOT NULL
);
```

| カラム名     | 型                 | 説明                      |
| ------------ | ------------------ | ------------------------- |
| id           | UUID (PK)          | 取引ID                    |
| space_number | CHAR(2)            | 駐車位置（'01'〜'20'）    |
| entry_time   | TIMESTAMP          | 入庫時刻                  |
| exit_time    | TIMESTAMP (NULL可) | 出庫時刻                  |
| fee          | INTEGER (NULL可)   | 確定料金（円）            |
| status       | VARCHAR            | `IN_PROGRESS` / `SETTLED` |

- 注意: 料金計算において、秒は切り捨てて計算されるが、DBには秒を含めて保持することとする。
