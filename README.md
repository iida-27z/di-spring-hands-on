## 概要
このハンズオンでは、Javaを用いて依存性の注入(DI)の概念を実際に体感しながら学ぶことができます。

## 学習目標
- クラスを分けないプログラムの問題点を理解する
- クラスを分けるときに発生する依存関係の問題を理解する
- 依存性の注入(DI)の基本概念を理解する
- Spring Bootの基本的な使い方を理解する

## 動作環境
- **推奨エディタ**: GitHub Codespaces(VSCode + DevContainer)
- **Java**: 25
- **ビルドツール**: Maven
- **接続先DB**: PostgreSQL
- **フレームワーク**: Spring Boot
